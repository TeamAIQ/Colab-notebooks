## How to use

**Colab notebooks**
1. Click **Open in Colab** next to the notebook.
2. Connect to a GPU runtime: **Runtime → Change runtime type → T4 GPU**.
3. Run the cells in order.

**Kaggle notebooks**
1. Click **Open in Kaggle** next to the notebook, then click **Copy & Edit**.
2. In the right panel, set **Session options → Accelerator → GPU T4 x2** and turn **Internet** on.
3. Run the cells in order.
